TECHNICAL DETAIL
GVM 코어 엔진
파일: sessions/s502-001/logos_eye_core.py
스택: YuNet ONNX SSD + HOG · Python 3.14 · PII 0.0%
모듈 설명
Logos Eye의 핵심 비식별화 엔진입니다. YuNet ONNX SSD와 HOG 하이브리드 방식으로 얼굴·신체를 감지하고 GVM(기하학적 벡터 마스킹)으로 즉시 비식별화합니다. 픽셀 원본은 메모리에서 즉시 파기되어 PII 누수율 0.0%를 수학적으로 보장합니다. Kalman 모션 예측으로 가림(Occlusion) 상황에서도 추적이 유지됩니다.
실제 사용 예시 USE CASES
시나리오 1 — 실시간 CCTV 스트림 비식별화
RTSP 스트림을 입력으로 받아 초당 28프레임으로 얼굴·신체를 감지하고 파란색 마스크를 씌웁니다. 처리된 프레임은 감사 인장이 찍혀 법적 증거로 활용 가능합니다.

실행 방법:
python sessions/s502-001/logos_eye_core.py --input cctv.mp4 --output masked.mp4
python sessions/s502-001/test_logos_eye.py # K-Pop 댄스 벤치마크

시나리오 2 — 하드웨어 핑거프린트 라이선싱
MAC/CPU ID 기반 암호화 서명으로 라이선스 없는 서버에서 실행 시 자동 차단. B2B 납품 시 불법 복제 방지.
