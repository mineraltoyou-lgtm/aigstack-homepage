특허 01: 안테나 엔진 (Antenna Engine)
구동 분류: 에지 단말 특화
엔지니어링 사양: vLLM / EXAONE 3.0 🇰🇷 / Python 3.10
엔지니어링 상세 해설
안테나 엔진은 유입되는 데이터를 의미론적 단위로 분할하여 이종 LLM 인스턴스에 독립 배분한 후, 동적 가중 다수결(Dynamic Weighted Majority) 방식을 통해 1차 진위를 결정하고 신뢰도가 임계치에 미달할 시 외부 유출을 선제적으로 차단하는 실시간 보안 게이트웨이 기술입니다.
실제 사용 예시 USE CASES
시나리오 1 — 언론사 AI 팩트체킹 시스템
뉴스 기사 초안이 입력되면 안테나 엔진이 EXAONE·Llama·Mistral 3개 모델에 동시 배분합니다. 각 모델이 독립적으로 "사실 / 허위 / 불확실" 판정을 내리고, 2개 이상 일치 시 통과, 불일치 시 즉시 차단됩니다.

▶ 실행 파일: sessions/s501-001/a_adaptive_filtering.py
▶ 실행 방법:
python a_adaptive_filtering.py
>>> from a_adaptive_filtering import AdaptiveFilter
>>> engine = AdaptiveFilter()
>>> result = engine.process({"payload": "북한이 핵실험을 했다고 한다"}, system_load=0.3)
>>> print(result["passed"]) # True / False
>>> print(result["reliability_score"]) # 0~100점

시나리오 2 — 금융 거래 데이터 사전 차단
이상 거래 데이터가 LLM 파이프라인에 주입되기 전, 안테나 엔진이 의미론적 이상 패턴을 탐지하고 신뢰 점수가 60점 미만이면 후속 연산 전 차단합니다. 금융사 내부망(폐쇄망)에서 vLLM + EXAONE 조합으로 데이터 이탈 없이 구동됩니다.

시나리오 3 — ChatGPT API 출력 2차 필터
OpenAI 응답이 돌아오면 안테나 엔진이 내용의 신뢰도를 재검증하여 환각(Hallucination) 의심 문장을 플래그 처리합니다. B2B SaaS로 API 형태 납품.
