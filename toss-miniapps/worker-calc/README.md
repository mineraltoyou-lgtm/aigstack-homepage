# 직장인·알바 계산기 (앱인토스 미니앱 #1)

토스 앱 안에서 돌아가는 계산기 미니앱이에요. 주휴수당, 월급 환산, 연차, 퇴직금을 계산해요.

- 2026년 최저시급 10,320원 기준
- WebView 방식 (Vite + TypeScript), SDK: `@apps-in-toss/web-framework` 3.8.0
- 수익: 하단 배너 광고 (`src/ads.ts`의 광고 그룹 ID를 넣으면 켜져요)

## 명령어

```bash
npm install
npm run dev      # 브라우저 미리보기 (토스 기능은 동작 안 함)
npm test         # 계산 로직 테스트
npm run build    # dist/ 생성 + worker-calc.ait 번들 생성
npm run deploy   # 콘솔 토큰 등록 후 업로드 (ait token add 먼저)
```

## 출시 체크리스트

1. [ ] 앱인토스 콘솔 가입 (사업자 명의) → 앱 등록, 앱 이름 `worker-calc`
2. [ ] 아이콘·스크린샷·설명문 등록
3. [ ] 콘솔에서 배너 광고 그룹 생성 → ID를 `src/ads.ts`에 입력
4. [ ] `npm run build` → `worker-calc.ait` 업로드 → 토스 앱에서 테스트
5. [ ] 검수 요청

## 계산 기준

| 항목 | 기준 |
|---|---|
| 주휴수당 | 주 15시간 이상, (주 근로시간 ÷ 40) × 8시간 × 시급, 최대 8시간 |
| 월급 환산 | (주 근로시간 + 주휴시간) × 365 ÷ 7 ÷ 12 (주 40시간 = 209시간) |
| 연차 | 1년 미만: 월 개근 시 1일(최대 11일) / 1년 이상: 15일 + 2년마다 1일(최대 25일) |
| 퇴직금 | 1일 평균임금 × 30 × 재직일수 ÷ 365, 평균임금 = 퇴직 전 3개월 임금(상여·연차수당 3/12 포함) ÷ 기간 일수 |
